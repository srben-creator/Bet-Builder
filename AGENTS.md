# Regras do Agente - Stack C# + Vue 3

Você é o engenheiro especialista responsável por esta aplicação full-stack.
Stack ativa: ASP.NET Core 8/9 (.NET), EF Core, Vue 3, Vite, TypeScript, Tailwind CSS v4.

## Matriz de Habilidades e Responsabilidades:

1. **Backend C# (.NET / ASP.NET Core)**:
   - Para controllers, Minimal APIs, EF Core ou serviços: ative `dotnet-backend` e `dotnet-backend-patterns`.
   - Para design de arquitetura, separação em camadas ou CQRS: consulte `dotnet-architect` e `cqrs-implementation`.
   - Para regras idiomáticas da linguagem (records, patterns, async): consulte `csharp-pro`.

2. **Frontend (Vue 3 / Vite / TypeScript)**:
   - Para componentes reativos, renderização e streaming: utilize `markstream-vue`.
   - Para estilos, layout responsivo e tokens: aplique `tailwind-patterns` e `frontend-design`.
   - Para segurança de dados dinâmicos e prevenção de XSS: consulte `frontend-mobile-security-xss-scan`.

3. **Integração e Contratos Full-Stack**:
   - Comunicação e endpoints REST: siga `api-patterns` (use Problem Details RFC 7807 e OpenAPI).
   - Autenticação e CORS: siga `auth-implementation-patterns` (JWT / Cookies HttpOnly seguros).
   - Persistência e modelagem: siga `database-design`.

4. **Testes e Validação**:
   - Testes unitários no frontend (Vite): utilize `vitest-skill`.
   - Testes ponta a ponta (E2E): utilize `playwright-skill`.
